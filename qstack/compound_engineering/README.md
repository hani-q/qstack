# Compound engineering plans

Each plan directory keeps the frozen design in `plan.html`, the live execution
record in `execution.md` when implementation has started, and the measured
result in `outcome.md` as checkpoints close. An outcome marked `in-progress`
does not grant authority for unfinished phases.
